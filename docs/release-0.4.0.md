# Solvit 0.4.0

- 内置“本地记忆”和“当前时间”JS 插件，首次启动离线安装但保持停用，用户启用后运行。
- 本地记忆以 TypeScript 编写：事实保存/更新/删除、重复合并、批量候选抽取、用户画像、关系图、文本分块、关键词检索和 JSON 导出。
- 记忆只需自己的存储权限，没有网络权限。经用户允许的工具检索/导出结果会发送给当前配置的模型。
- 停用撤销工具，卸载插件保留数据，重新启动不自动装回卸载的内置包。
- 新增 TS SDK、独立打包工具、纯 JS 包依赖打包和示例；市场包与 Android 离线包由同一源码生成。
- 发布同时检查 TS、插件与市场测试，以及 Android 测试、Lint 和 APK 构建。

使用：插件 → 已安装 → 启用“本地记忆”，授予插件存储权限；再在聊天中请求“记住我喜欢 Kotlin”或“查找以前的偏好”。每次工具调用都需确认。配置的模型必须支持工具调用。

检索目前是 BM25 关键词评分和中文字符/双字索引，尚未接入向量混合检索、自动上下文 Hook 或后台抽取。画像/关系/文档管理目前通过聊天工具或插件试运行完成，专门管理页和文件导入/导出仍待实现。

真机、真实模型行为和完整交互尚未验证；MCP、Skills、角色绑定、Root/Shell、附件等完整产品目标继续推进。

固定签名沿用 0.1.1 起的版本；早期 0.1.0 临时签名无法覆盖安装，请保留有重要聊天记录的旧版数据。
