# Solvit 0.3.0

- 聊天可自动发现已启用插件的工具，并接收模型返回的结构化工具调用。
- 执行前逐次确认工具描述和完整参数；支持拒绝、停止、执行状态和结果展开查看。
- 工具结果回传模型继续生成，默认最多 8 轮、16 次工具执行，执行超时从用户确认后开始。
- 支持 OpenAI 兼容 SSE 工具调用分片和 JSON 响应，拒绝不完整、重复或未知调用。
- 工具调用与结果持久化，失败/中断记录保留但不进入后续上下文；SQLite 事务和旧库迁移保护已有聊天。
- 增加真实 HTTP Provider → 确认 → QuickJS 插件 → 模型结果回传的集成测试，以及 SQLite 迁移与回滚测试。

需要模型支持 Chat Completions 工具调用。请先安装并启用“当前时间”等插件，再在聊天中请求使用工具。

尚未验证真机安装、真实模型调用和完整交互体验。MCP、Skills、长期记忆、角色绑定、Root/Shell、附件和其他完整产品目标仍在后续工作范围。
