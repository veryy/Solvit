# Solvit 0.15.3：实际请求与回复耗时诊断

- 设置底部新增“诊断 → 最近请求诊断”，查看最近组装请求的角色、协议、模型、消息数量、上下文来源与实际提供的工具。
- 工具后续轮次也更新诊断；采用过滤后的工具集，便于检查角色绑定与插件是否真正提供给模型。
- 显示首段文本/思考到达应用、首段文字显示、模型事件结束和显示结束的耗时，区分接收等待与显示排队。工具执行和审批也可能包含在整体耗时中。
- 诊断只保留内存中的元数据，不保存提示词正文、API 密钥、授权 Header 或工具参数；不会把上一次请求和较新的发送尝试混合展示。
- 新界面文案支持中文、英文、日文、韩文、西班牙文和法文；保留 0.15.2 的全部功能。

[功能分支远程验证通过](https://github.com/veryy/Solvit/actions/runs/38160317381)：单元测试、Lint、APK、固定签名及 Android 模拟器界面检查。模拟器实际运行 Agent → Provider 准备 → 聊天 → 设置诊断流程；Provider 使用受控响应，没有以此宣称真实模型已验收。

版本码 22，保持既有签名，可覆盖更新并保留数据。“到达应用”是解析后事件时间，不是网络首字节时间，不能单独用来证明服务器缓冲。搜索浏览器升级在后续分支继续实现，本包不包含尚未完成的搜索升级。
