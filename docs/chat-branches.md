# 聊天分支

聊天消息旁的操作菜单提供两种方式：

- 助手回复 → 从这里分支：复制到这一整轮回复结束为止的记录，包括中间工具调用、结果、思考和最终回答。
- 用户问题 → 编辑并分支：复制该问题之前的记录，编辑后的问题放入新分支输入框，由用户发送，不会自动请求模型。

原对话继续保留。分支拥有独立消息 ID 和记录；删除或继续原对话不会改动分支。分支来源 ID 保存在会话元数据中，原对话删除后来源信息仍保留，不作为外键约束。分支保留消息的失败/中断状态，后续模型上下文仍按原有规则排除未完成回复和思考内容。

## 服务与存储

`builtin.chat.branches` 是独立 Kotlin 宿主插件，通过 `ChatBranchService` 提供分支能力，依赖可替换 `ChatStore`、角色与工作区服务。聊天 UI 只调用接口。存储实现需支持 `forkSession`：在同一事务中读取边界、创建会话及复制完整前缀。SQLite 实现提供这一保证；其他存储未实现时明确拒绝该能力。数据库升级至 v4，为旧会话添加可空的来源字段，不改动旧消息。

分支继承所选角色，包含其插件/Skills 范围。已有工作区会绑定同一目录与 Shell；没有工作区时不创建目录或 Shell。分支不是工作区文件快照，分支中的文件操作会影响共享目录，原对话的终端进程也不会被复制。

角色或工作区绑定失败时删除新分支并撤销其绑定，原对话保持完整。正在生成或创建分支时不允许同时切换、删除或继续发送消息。

该能力不授予 JS 读取全部聊天记录的权限；模型工具与 JS API 的扩展仍按宿主权限边界增加。
