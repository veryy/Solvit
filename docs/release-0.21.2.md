# Solvit 0.21.2：模型设置字段稳定性

模型名称及协议参数使用稳定的列表键，使参数菜单状态跟随对应字段；模型设置回归改用 AndroidX 官方按键滚动接口，并连续三次重新打开已保存配置，检查输出限制和思考模式。

这是对0.21.1发布时已出现的设置测试异常的针对性调整。此前异常位于按后代节点查找的滚动路径；没有跳过该用例或删除断言，也不宣称已经修复AndroidX所有跨线程语义树读取问题。参考实现、原失败证据及验证范围见[阶段记录](https://github.com/veryy/Solvit/blob/v0.21.2/docs/model-settings-stability-stage.md)。

[发布前远程验证](https://github.com/veryy/Solvit/actions/runs/38244926746)通过构建、Lint、固定签名及覆盖升级检查。实际XML报告271个单元和42个模拟器测试全部通过，均无错误或跳过，包含连续三次重开的设置用例。正式标签仍需通过插件、公开搜索、模拟器和发布门禁。

保留0.21.1的角色请求修正，角色实际模型回答与真机验收仍未完成。本次未运行本地Android或TS构建/测试。
