# Solvit 0.21.2：模型设置字段稳定性

模型名称及协议参数使用稳定的列表键，使参数菜单状态跟随对应字段；模型设置回归改用 AndroidX 官方按键滚动接口，并连续三次重新打开已保存配置，检查输出限制和思考模式。

这是对0.21.1发布时已出现的设置测试异常的针对性调整。此前异常位于按后代节点查找的滚动路径；没有跳过该用例或删除断言，也不宣称已经修复AndroidX所有跨线程语义树读取问题。参考实现、原失败证据及验证范围见[阶段记录](https://github.com/veryy/Solvit/blob/main/docs/model-settings-stability-stage.md)。

[发布前远程验证](https://github.com/veryy/Solvit/actions/runs/38244926746)通过构建、Lint、固定签名及覆盖升级检查。实际XML报告271个单元和42个模拟器测试全部通过，均无错误或跳过，包含连续三次重开的设置用例。[正式标签运行](https://github.com/veryy/Solvit/actions/runs/38246821214)第二次尝试全部成功并发布，包括插件、公开搜索与模拟器门禁；实际成功报告271个单元、42个模拟器测试无失败、错误或跳过。

首次正式尝试只有已有记忆页面用例在滚动后点击筛选按钮时找不到节点而失败，设置用例仍通过。原条件重跑后记忆用例通过，其点击/输入法时序问题的根因仍未确认，不把重跑成功当作修复。该失败现场及下一步排查依据已保留。

公开APK已实际下载，与正式构建产物逐字节一致。稳定签名和覆盖升级检查通过。

保留0.21.1的角色请求修正，角色实际模型回答与真机验收仍未完成。本次未运行本地Android或TS构建/测试。
