# Solvit 0.25.2：保存执行时的完整文件副本

工作区执行记录为受限 UTF-8 文本保存当时的完整副本。后续再次修改文件或重开应用，不会改变旧记录中的副本。SQLite schema9 兼容旧数据；旧记录没有全文时明确缺失，不读取当前文件补造历史。

单文件256KiB、每次快照2MiB、单次执行32MiB、全局128MiB；相同内容SHA-256去重，删除最后一个所属对话后回收。二进制、超限和原有凭据过滤策略识别的敏感内容不保存全文；预算不足保留观察元数据。读取核验会话、执行、事件、路径和摘要，并支持撤权与取消。
