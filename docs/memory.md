# 本地记忆插件

`dev.solvit.memory` 用 TypeScript 编写，经 SDK 打包为独立 JS 插件；市场与 App 的离线包使用同一份产物。业务实现位于 [builtin-plugins/memory](../builtin-plugins/memory/index.ts)，Kotlin 只提供授权与私有存储桥接。

## 使用

新版 App 在首次启动时提供“本地记忆”和“当前时间”两个已安装、未启用的插件。在“插件 → 已安装”启用本地记忆并授予“插件自己的持久化存储”权限。之后可以在聊天中说：

- “记住我喜欢 Kotlin，保存为偏好。”
- “根据之前的记忆，我喜欢什么开发语言？”
- “把我刚才明确提到的偏好抽取并保存，避免重复。”
- “更新这条记忆……”或“删除记忆 m1。”
- “保存用户画像：城市是上海。”
- “把这段资料保存为文档，之后按关键词查找……”

模型需要支持工具调用，也可能选择不调用工具。每次调用都显示工具名和完整参数，用户允许后执行；可以拒绝或停止。也可以在插件页面手动试运行工具。

插件没有网络权限，数据保存在该插件的私有本机存储里。被用户允许的检索、导出等工具结果会传回当前配置的模型服务；本机保存不意味着工具结果不会进入模型上下文。

## 数据与检索

- 事实：ID、文本、类别、标签、创建和更新时间。同文本同类别经大小写/空白归一后合并标签；提供 ID 时更新该条记录。
- 抽取：模型把明确事实作为候选数组提交给 `memory_extract`，确认后一次保存，最多 20 条。插件本身不额外调用模型，不后台推断用户信息。
- 画像：最多 64 个属性，可修改；value 为 null 时删除。画像会参与关键词检索。
- 关系图：已有记忆之间的有向关系，支持建立、解除、查询直接邻居；删除记忆时移除关联关系。
- 文档：最多 30000 个 UTF-16 字符；按 Unicode 字符分为 600 字符窗口、80 字符重叠，更新同 ID 替换旧分块，支持删除。
- 搜索：事实、画像、文档分块共同使用 BM25 评分；英文按单词，中文使用字符与相邻双字。返回来源、ID 和得分。尚未实现向量嵌入、语义与关键词混合检索，拼写变体和同义词可能检索不到。
- 容量：最多 256 条事实、512 个关系、512 个分块，整个数据库不超过 220 KiB UTF-8；超限拒绝写入并保留已有数据。

`memory_export` 返回完整 JSON 数据库供查看或备份。现在没有文件导出/导入页面；需复制工具结果。停用撤销工具，卸载插件保留数据且下次启动不自动重装；清除 App 数据或卸载 App 会清除本机记忆。

## 验证与后续范围

TS 插件测试覆盖重载持久化、重复合并、批量校验、中文英文检索、画像、关系删除、Unicode 分块、容量和写入失败。Android 宿主测试覆盖离线安装、授权、真实 QuickJS 执行、SharedPreferences 持久化、重启、撤销授权和卸载。

后续继续实现角色绑定、自动上下文 Hook、后台抽取策略、向量嵌入与混合检索、文档文件导入和记忆管理页面。真机交互与真实模型行为尚未验证。
