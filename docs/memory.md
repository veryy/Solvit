# 本地记忆插件

`dev.solvit.memory` 用 TypeScript 编写，经 SDK 打包为独立 JS 插件；市场与 App 的离线包使用同一份产物。业务实现位于 [builtin-plugins/memory](../builtin-plugins/memory/index.ts)，Kotlin 只提供授权与私有存储桥接。

## 使用

App 内置未启用的本地记忆插件。在“插件 → 已安装”启用时，查看并授权当前清单声明的私有存储/模型权限；自定义角色还须绑定记忆插件。之后可以在聊天中说：

- “记住我喜欢 Kotlin，保存为偏好。”
- “根据之前的记忆，我喜欢什么开发语言？”
- “把我刚才明确提到的偏好抽取并保存，避免重复。”
- “更新这条记忆……”或“删除记忆 m1。”
- “保存用户画像：城市是上海。”
- “把这段资料保存为文档，之后按关键词查找……”

记忆插件 1.1.0（宿主 API 7）默认自动把相关已保存记录和用户画像提供给模型，附上来源、ID 和更新时间，不再依赖模型主动调用检索工具。自定义角色仍需绑定此插件。保存新记录、修改和删除需要模型工具调用，并经过授权；自动检索与回复后的后台抽取是两条独立链路。后台抽取已在0.19.0加入，但默认关闭，须明确授权并开启；可查看/取消任务，真实模型抽取质量尚未验收。

在“插件 → 已安装 → 本地记忆”停用后进入“配置插件”，可关闭“自动将相关记忆用于聊天”，保存并重新启用，仍可使用手动记忆工具。关闭时不读取存储；停用或角色未绑定也不注入。每个模型步骤重新检索，工具更新后的记录不会继续使用旧快照。

已安装 1.0.0 的用户需在市场更新到 1.1.0 并重新启用；不静默开启旧插件的自动上下文。新安装版本的启用说明会提示资料可能提供给当前模型服务。

插件没有直接网络权限，数据保存在该插件的私有本机存储里。显式开启后台抽取后会通过受控模型服务处理已完成对话；启用自动检索后，相关记录会作为上下文传给当前模型；被用户允许的检索、导出等工具结果也会传回当前配置的模型服务；本机保存不意味着工具结果不会进入模型上下文。

## 数据与检索

- 事实：ID、文本、类别、标签、创建和更新时间。同文本同类别经大小写/空白归一后合并标签；提供 ID 时更新该条记录。
- 抽取：模型把明确事实作为候选数组提交给 `memory_extract`，确认后一次保存，最多 20 条。该手动工具本身不额外调用模型。另有默认关闭的后台抽取能力，见[自动记忆阶段](automatic-memory-stage.md)。
- 画像：最多 64 个属性，可修改；value 为 null 时删除。画像会参与关键词检索。
- 关系图：已有记忆之间的有向关系，支持建立、解除、查询直接邻居；删除记忆时移除关联关系。
- 文档：最多 30000 个 UTF-16 字符；按 Unicode 字符分为 600 字符窗口、80 字符重叠，更新同 ID 替换旧分块，支持删除。
- 搜索：事实、画像、文档分块共同使用 BM25 评分；英文按单词，中文使用字符与相邻双字。返回来源、ID 和得分。尚未实现向量嵌入、语义与关键词混合检索，拼写变体和同义词可能检索不到。
- 容量：最多 256 条事实、512 个关系、512 个分块，整个数据库不超过 220 KiB UTF-8；超限拒绝写入并保留已有数据。

`memory_export` 返回完整 JSON 数据库供查看或备份。现在没有文件导出/导入页面；需复制工具结果。停用撤销工具，卸载插件保留数据且下次启动不自动重装；清除 App 数据或卸载 App 会清除本机记忆。

## 验证与后续范围

TS 插件测试覆盖重载持久化、重复合并、批量校验、中文英文检索、画像、关系删除、Unicode 分块、容量和写入失败。Android 宿主测试覆盖离线安装、授权、真实 QuickJS 执行、SharedPreferences 持久化、重启、撤销授权和卸载。

角色绑定已有；自动上下文 Hook 已通过 [0.17.0 远程验证](https://github.com/veryy/Solvit/actions/runs/38167779375)。全请求预算/持久摘要、默认关闭的后台抽取和记忆管理页面已有，实际模型质量仍待验收。向量嵌入与混合检索、文档文件导入继续保留。真机交互与真实模型行为尚未验证。
