# Solvit 0.25.1：保存执行时的完整文件副本

工作区执行记录现在为受限 UTF-8 文本保存当时的完整副本，不再只保存预览片段。后续再次修改文件或重开应用，不会改变旧记录中的副本。SQLite schema9 兼容旧数据；旧记录没有全文时仍明确缺失，不读取当前文件补造历史。

单文件最多256KiB、每次快照2MiB、单次执行32MiB、全局128MiB；相同内容按SHA-256去重，删除最后一个所属对话后回收。二进制、超限和包含原有凭据过滤策略识别的敏感内容不保存全文；预算不足保留观察元数据。副本读取核验会话、执行、事件、路径和内容摘要，并支持撤权与取消。

这是完整文件差异功能的存储阶段，聊天里的现有预览仍是片段；JS/TS差异计算及插件HTML审阅页面接着实现。本版本不宣称完整diff或真实Agent任务已经交付。

build53/API16，沿用固定APK签名，正常覆盖更新保留设置和数据。专项远程报告实际285个测试，0失败/错误/跳过，包括新增原生捕获、SQLite和凭据过滤回归。正式构建及APK链接由本发布页提供。
