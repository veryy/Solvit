# Solvit 0.2.0

- 新增原生插件市场：从 HTTPS 目录安装、SHA-256 和大小校验、启停、卸载与版本更新。
- 支持纯 JS 工具插件：独立 QuickJS 引擎、插件依赖、权限授予、私有持久化存储、HTTPS GET、手动工具试运行。
- 执行限制：32 MiB JS 内存、512 KiB 栈、30 秒引擎期限；异步等待有超时保护，停用和卸载撤销工具并回收引擎。
- 市场已有当前时间插件示例。TypeScript 需要发布前打包成 JS，宿主没有 Node.js/npm 运行时。
- 保留 0.1.1 的 GitHub Release 更新卡片和固定 APK 签名。

通过 GitHub Actions 单元测试、Lint 与 debug APK 构建。尚未验证真机安装、市场完整交互或真实模型调用；模型自动调用工具、MCP、Skills、长期记忆和 Root/Shell 仍在后续工作范围。

0.1.1 起使用固定签名。最初的 0.1.0 临时签名不能覆盖安装；当前没有聊天导出功能，请保留有重要聊天记录的旧版数据。
