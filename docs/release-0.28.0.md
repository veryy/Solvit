# Solvit 0.28.0：工作区文件工作台

工作区插件提供离线 HTML/JS 文件树和 CodeMirror 文本/代码预览、编辑；与当前对话绑定的 Shell 共用目录。

- 文件树按需展开目录和分页加载；手机文件面板可收起，点文件进入预览。
- 完整 UTF-8 文本预览和编辑，最多256KiB；行号、JavaScript/TypeScript、JSON、Python、HTML、CSS语法高亮、搜索及撤销。
- 新建文本和目录、重命名/移动、删除前预览并确认；取消确认不修改文件。
- 保存先暂存完整文档，再确认一次提交；文件被外部修改时拒绝覆盖，关闭页面清理暂存。
- API18市场保留API1–17原目录；旧版仍获取兼容工作区包，新版获取1.4.0文件工作台。保留原插件设置、授权和明确卸载选择。

实际Android模拟器已覆盖真实键盘输入、约90KB中文/emoji文档保存与完整重开、外部修改冲突、目录动作、Shell创建文件后页面读取，以及展开文件树保持当前文档、点击切换文件。完整发布构建结果以本次Actions链接为准。

当前预览支持文本/代码；图片、PDF等二进制预览和超限文件编辑尚未实现。宽屏并排样式尚未实测。Git工作树Changes、暂存/提交和GitHub远程操作继续开发；已有“文件变更”页是执行记录的保存快照，不是Git状态。真实模型自主项目任务和真机体验尚未验收。
