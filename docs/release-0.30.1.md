# Solvit 0.30.1：未发布的重试候选

正式38520588469的键盘页面用例跨线程观察失败，Release未发布。保留原标签，后续修复候选为0.30.2；下方为原候选范围，不是可下载交付证明。

网络或模型请求失败后，可以在原回复里点「重试回复」。停止生成的最后一条回复也可以重试。build61 / 插件 API20。

- 使用原用户消息和原附件重新请求模型，图片与文本不会丢失，也不会重复添加一条用户消息。
- 新结果继续在同一个气泡内流式显示，旧的失败回复默认折叠，可展开查看。
- 原执行记录与文件差异保留；数据库升级允许同一用户消息的多个执行尝试，同时仍限制同一对话只有一个运行中的任务。
- 过期按钮、成功回复和忙时重试会被拒绝；角色、当前模型连接、工作区和工具授权继续生效。
- 重试结束后原等待队列保持暂停，可手动继续。重试会重新请求模型，可能再次执行工具；没有自动重试或操作幂等保证。
