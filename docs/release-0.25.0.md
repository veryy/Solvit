# Solvit 0.25.0：JS/TS工作区项目规则（候选）

启用工作区与Shell插件并授权后，每个模型步骤会由TS插件读取当前绑定目录根的AGENTS.md、CLAUDE.md及local补充，整理来源和重复内容后加入当前请求。可在插件配置关闭自动规则；未绑定工作区的普通聊天不创建目录。

API16、工作区插件1.2.0、build52。专用只读Hook不接受路径或其他工作区，保留角色过滤和实时授权；读后撤权或绑定变化不会返回规则正文。严格UTF-8、大小和符号链接边界由宿主核验，TS限制渲染预算并明确省略/截断；旧规则投影不写入持久聊天历史。旧API1–15包及已修改/卸载状态保留，固定APK签名沿用。

完整正式门禁、线上部署及公开APK尚未完成，具体进度见[阶段记录](https://github.com/veryy/Solvit/blob/main/docs/workspace-instructions-stage.md)。根目录规则不是完整嵌套作用域、文件diff或Agent任务验收；真实模型遵守规则、角色/流式/工具选择、真机及完整JS内核仍未验收。
