# Solvit 0.15.0

- 模型配置可选择 OpenAI 兼容或 Claude / Anthropic 原生协议；协议插件独立注册请求、模型目录和设置参数，聊天 UI 与 Agent 通过服务接口调用。
- Claude 使用 Messages API，支持流式文本、折叠思考、原生工具声明、参数增量、授权执行及工具结果回传。思考签名和隐去思考数据单独保存，贯穿工具轮次、SQLite 历史和聊天分支。
- Claude 模型列表支持分页和显示名称；独立订阅地址不会默认收到模型 API Key。最大输出令牌、思考模式和手动预算按插件声明显示；具体模式支持由模型和服务决定，错误详情可在应用内查看。
- 长消息和原生转录按 UTF-8 字节分块读取，避免 Android CursorWindow 的整行限制；中文、表情和空字符保留。
- 配置和加密备份包含协议及参数；旧配置继续默认 OpenAI 兼容。工具后续轮次采用原发起轮次的原生思考参数。历史系统指令或工具改变时，已完成旧轮次的思考块不再回传；未完成工具轮次的签名上下文改变会明确失败。
- 新设置与错误文案继续支持中文、英文、日文、韩文、西班牙文、法文；中文仍为默认语言。固定签名继续用于覆盖更新。

[GitHub Actions 验证通过](https://github.com/veryy/Solvit/actions/runs/38144065045)：145 个单元测试、26 个 Android 模拟器测试、Lint、APK 和固定签名检查；包含实际 HTTP 协议回传、跨协议任务路由、长记录字节边界与大行限制、协议设置、旧版覆盖安装的数据保留。尚未使用真实 Claude 账户或真机验证。Gemini、本地推理、附件、摘要、混合记忆检索、Linux/SSH/SFTP 和其他权限能力继续按完整产品清单推进。
