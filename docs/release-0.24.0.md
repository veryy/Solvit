# Solvit 0.24.0：JS Agent 观察与工具参数审核

API15增加明确授权的 `agent.read`、`observe()` 和 `decline(index)`。JS/TS策略可读取本轮用户请求、角色名称、模型正文/思考、工具参数与结算结果，并拒绝某个拟调用；拒绝事实按原顺序回传模型。宿主继续处理完整消息协议、Provider签名、工具审批、取消、存储与资源限制。
