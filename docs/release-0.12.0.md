# Solvit 0.12.0

## 聊天分支

- 助手消息旁“消息操作 → 从这里分支”，保留这轮结束前的完整历史，包含工具调用、结果、思考与最终回复。
- 用户消息旁“消息操作 → 编辑并分支”，保留旧问题之前的历史，并把修改后的问题放到新分支输入框，由你发送。
- 原对话保持完整；分支记录独立，删除或继续原对话不会修改分支。
- 继承所选角色和插件/Skills 范围。有工作区时共享同一目录与 Shell，没有工作区时不自动创建。工作区文件和终端进程不会复制。
- 使用独立分支服务插件、可替换聊天存储接口及 SQLite 事务复制。数据库 v4 保留旧数据并添加来源字段。

## 验证与边界

发布检查包含分支边界、完整工具轮次、替换存储、绑定失败回滚、数据库升级/重开，以及模拟器中的回复分支、编辑预填、角色/工作区继承和删除原对话后的保留。

保留 0.11.0 的折叠工具/思考、Markdown、按需工作区，以及键盘上方的聊天和终端输入区。沿用 0.7.0 起的固定签名，支持覆盖更新。

尚未完成真机与真实模型在 Android 上完整操作分支和工具的联动验证。附件、摘要和上下文窗口管理仍在后续范围内。
