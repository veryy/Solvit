# Solvit 0.16.0：浏览器搜索与动态正文

- 默认搜索无需填写密钥，优先读取 Bing 公开搜索页；失败尝试 DuckDuckGo，再使用基本关键词过滤的 RSS 备选。
- 通过真实 Android WebView 提取标题、正文和结果区链接，支持页面完成加载后的初始 JavaScript DOM 更新；正文读取失败可回退静态获取。
- 校验最终地址仍是搜索页，排除首页重定向、引擎内部链接、重复来源和无关结果；提供摘要、来源及进一步读取提示。
- 浏览器是独立 Kotlin 服务，搜索策略保留在 TS 插件。API 6 桥要求 network 授权及实际工具调用上下文，Hook 和启停回调不能启动浏览。
- 浏览器、HTTP 调用和返回结果都有期限或大小限制，停止后回收资源；默认公开搜索不向网页发送模型或插件配置的授权凭据。
- 官方旧搜索插件升级保留配置和启用状态；市场仍向 API 2–5 客户端提供旧兼容包，新客户端获取 1.2.0。

[功能远程验证](https://github.com/veryy/Solvit/actions/runs/38162369617) 通过测试、Lint、APK、固定签名和 Android 模拟器检查；下载单元 XML 核对 159 个测试无失败、错误或跳过。JS 搜索→宿主→模型后续工具轮次、授权拒绝及停用受控集成通过；真实 WebView 离线文档执行异步 DOM 修改并提取链接通过。

[公网来源检查](https://github.com/veryy/Solvit/actions/runs/38162369636) 使用同一 TS 搜索包和 Android DOM 脚本，在 Chromium 上取得中英文官方来源及正文；这不能代替真实模型最终引用和真机网络验收。[时效检查](https://github.com/veryy/Solvit/actions/runs/38163223079) 已通过：从 Kotlin 官方发布接口取得当前稳定版本，正文包含该版本；此检查未验证真实模型最终回答。公网引擎存在波动，失败须明确返回，没有结果时不编造。

版本码 23，保留既有签名、角色/流式修复和请求诊断。标签构建还会检查 TS/市场、公网搜索与时效，再自动发布 APK。尚未进行真机与真实模型的完整搜索联动，也未宣称任意异步网页、登录页面或所有查询均可用。
