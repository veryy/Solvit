# 后台自动记忆：持久来源与候选任务

## 已核对的上游源码

- Operit `dbf71916fae9750cfdc9f9a774f5a0fee56633fb`：`data/model/MemoryAutoSaveCandidate.kt`、对应 `MemoryAutoSaveCandidateTest.kt`、`api/chat/library/MemoryAutoSaveScheduler.kt`。候选带来源消息、状态、尝试次数；按资料空间分组，批次有上限，单个调度器不并发运行。失败保留候选，不阻塞普通聊天。
- DSH `d743267388641bc76f17c45ce8b4c231aed1d32c`：`packages/core/agent-loop/src/agent.ts` 的 `step/end`、`turn/end` 持久记录，以及 `tests/cancel.spec.ts` 对中断和完成的区分。只有完整结束的回合可成为自动抽取来源，中断不能冒充完整回复。

采用行为和数据约束，未复制上游代码。Android 使用现有 SQLite、Coroutine 与 QuickJS，后续抽取/合并策略由 TS 插件提供；模型密钥由 Kotlin 宿主持有。

## 当前候选实现

`CompletedChatTurn` 记录用户/最终助手消息 ID、当轮角色名称/插件范围、所请求的模型配置 ID 与 Provider/模型名称。它不保存正文、角色提示词或密钥。模型名称描述请求起点，不宣称是工具后续轮次实际路由。

SQLite 数据库候选版本 7：回复批次、来源记录和明确准入的后台任务在同一事务提交。来源必须对应当前完整用户消息与完整最终回复。失败、取消与旧数据库迁移不生成候选。新聊天分支保留消息但不复制后台任务，删除聊天级联删除任务。

`PostTurnHookRegistry` 在发送前检查明确开关与角色绑定，并记录确切插件版本/SHA-256。发送开始后才启用的 Hook 不会追溯准入；停用、卸载或换包仍需在实际运行时再次检查。没有注册 Hook 的聊天不会产生后台任务；不支持原子来源的替代存储不准入后台工作，普通聊天仍可用。

任务具有等待、运行、完成、失败和跳过状态，按尝试次数进行条件领取及结算，过期执行不能覆盖后续状态。进程中断后的运行状态可恢复为明确失败；失败只允许显式重试，最多三次。存储只接收枚举错误分类，不保存任意异常、模型输出或密钥。读取来源与任务均有分页上限。

## 尚未完成

目前没有发布自动抽取功能或新 APK。后台消费者、JS/TS `afterTurn` 桥、受限模型调用、默认关闭的自动保存开关、带来源的合并/去重、原生任务状态和重试/删除入口仍需实现。当前公开最新版继续为 0.18.0。

后续处理必须重新核验当前开关、角色范围、插件校验值和模型配置；不自动重放中断的写入。TS 插件只通过宿主获得受限推理结果，不能获取 Provider 密钥，也不能借后台 Hook 执行 Shell、网页或任意工具。模型请求有全局预算与期限，抽取任务不阻塞聊天接收/展示。写入结果按来源幂等，防止写入完成但任务结算前退出造成重复事实。
