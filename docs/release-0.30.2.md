# Solvit 0.30.2：在原对话里重试回复

网络或模型请求失败后，可以在原回复里点「重试回复」。停止生成的最后一条回复也可以重试。build62 / 插件 API20。

- 使用原用户消息和原附件重新请求模型，图片与文本不会丢失，也不会重复添加一条用户消息。
- 新结果继续在同一个气泡内流式显示，旧的失败回复默认折叠，可展开查看。
- 原执行记录与文件差异保留；数据库升级允许同一用户消息的多个执行尝试，同时仍限制同一对话只有一个运行中的任务。
- 过期按钮、成功回复和忙时重试会被拒绝；角色、当前模型连接、工作区和工具授权继续生效。
- 重试结束后原等待队列保持暂停，可手动继续。重试会重新请求模型，可能再次执行工具；没有自动重试或操作幂等保证。

## 验证与边界

发布前[候选验收](https://github.com/veryy/Solvit/actions/runs/38523103982)通过测试、Lint、APK、固定签名、模拟器和覆盖升级；实际 XML 报告435单元和57模拟器用例通过，零失败、错误或跳过。实际附件页面检查HTTP500→点击重试→HTTP成功，失败和重试请求正文（含图片与文本字节）一致，原用户消息列表不变。正式发布另运行插件、市场、公开搜索和MCP/Skills门禁，结果见下方构建链接。

本版先支持最后一条失败/停止的回复。任意历史答案的完整变体选择、编辑旧用户消息带回附件、PDF、未发送附件清理、工作区导入以及队列进程死亡恢复仍待完成。图片理解、角色与工具的真实模型任务和真机体验尚未验收。屏幕操控继续暂缓。

完整记录见[重试阶段](https://github.com/veryy/Solvit/blob/v0.30.2/docs/chat-retry-stage.md)，后续优先级见[产品路线](https://github.com/veryy/Solvit/blob/v0.30.2/docs/product-roadmap.md)。

0.30.1 的正式验收遇到键盘页面测试跨线程观察错误，未发布。本版修复测试线程读取，保留原键盘位置和焦点断言；原用例连续3次及完整模拟器验收通过。Linux/PRoot 环境和 Python、Node.js 安装已列入后续工作，本 APK 尚不包含该环境。
