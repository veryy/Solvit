# Solvit 0.14.0

- 模型设置升级为多配置管理：新增、编辑、复制、删除独立连接，每组有自己的地址、模型、密钥、订阅地址和系统提示词。
- 分别选择聊天模型和工具后续模型。首轮使用聊天模型；模型发起工具调用并收到执行结果后，后续轮次可发往另一组连接，收到完整对话和工具结果。未单独选择时沿用聊天模型。后续轮次只切换连接和模型，系统提示词继续采用聊天配置与当前角色。
- 原有单模型连接自动读取为默认配置。模型配置服务是独立 Kotlin 插件，UI 与 Agent 依赖核心接口；所有配置和任务绑定整体加密保存，禁止直接删除正在用于任务的配置。
- 配置备份包含全部模型连接与任务绑定；仍能导入以前的单模型备份。密钥无法解密时保留原始数据，提示使用备份恢复，避免编辑操作静默覆盖其他配置。
- 新页面文案继续支持六种界面语言，固定 APK 签名与聊天记录保持兼容。

当前提供 OpenAI 兼容协议和聊天/工具后续两类任务路由；其他原生协议、摘要/嵌入模型及本地推理尚未实现。未完成真机或真实模型账户之间切换的完整联动验证。
