# Solvit 0.26.0：插件 HTML 文件差异页

在同一条助手消息的执行记录中打开“文件变更”，查看执行时保存的文件差异。增删配色、行号、分页和详情由工作区 JS/TS 插件及 HTML 绘制；副本信息默认折叠。使用 jsdiff，完整许可随插件资源分发。

差异只使用所选执行的历史副本；后来改写文件、重开页面或应用不会把当前文件混入历史。旧记录、敏感内容、二进制、超限或预算不足时明确显示副本不可用。单文件全文限256KiB，长 Unicode 行安全分页；差异计算超时则明确显示整段删除与添加。

工作区插件1.3.0/API17：执行页与管理页分别声明，执行页必须由宿主绑定选定的对话和执行，不能从插件详情直接打开。原版1.2.0自动升级并保留开关、配置与授权；用户修改过或卸载的包保持原状态。市场保留旧版包供旧客户端使用。

本版还修正启动初始化结果从后台线程发布引发的 Looper 异常；后台初始化完成后，界面状态在主线程更新。已有复现序列十轮×三项通过。

build55，沿用固定APK签名。远程测试、Lint、签名、覆盖安装与APK门禁完成后发布，不替换旧版本附件。页面回归使用真实 Android 文件捕获、SQLite重开、QuickJS和WebView，仍不等同于真实模型任务。

真机、真实模型的角色遵循、流式时延、工具选择及完整工作区任务仍待验收。
