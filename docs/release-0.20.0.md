# Solvit 0.20.0：插件自带界面

新增 JS/TS 插件页面：插件定义列表、卡片、表单、按钮和关系图，应用统一渲染主题、语言、确认窗口及键盘边距。每个页面使用独立执行实例；停用、卸载或更新会关闭旧页面，写入时重新检查授权。

记忆插件提供事实搜索、角色/类别筛选、分页、来源详情、编辑/删除和实际关系查看。人工编辑保留来源并保护记录；并发变化会保留草稿，避免覆盖新数据。设置入口使用 APK 内置 TS 页面，插件停用后仍可管理已有数据。

后台任务页提供状态、来源消息、尝试次数、重试、删除、停止和完成清理。重试明确提示费用，宿主把确认绑定到具体任务和尝试；旧按钮不能停止新尝试。删除任务与清理不会删除聊天或已保存事实。

便签插件是额外的可安装界面示例，App 没有便签专用页面。市场继续向 API 8 App 提供原来的记忆 1.2.0 包，新界面需要 API 9。

关系图采用有界布局和缩放/拖动，不是 Operit 的完整聚类算法；画像和文档当前提供预览。尚未进行真机、真实模型自动记忆质量或完整 Android Agent 任务验收。

此文件随候选源码编写，发布状态以 GitHub Release 和对应 Actions 实际结果为准。
