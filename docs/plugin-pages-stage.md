## 第一个实现检查点

SDK 增加原生页面节点、页面输入与事件类型；Android 增加独立的 `ScriptPageView` 校验器。支持文本、容器、卡片、按钮、字段、选择器和关系图数据。限制 UTF-8 字节、组件数、深度、字段长度及图规模；拒绝未知组件/字段、重复 ID 和悬空关系。

事件从当前显示节点派生 action，不能传入任意处理器名字；选择/图点击值必须存在于当前数据，表单字段必须属于当前页面。禁用按钮拒绝执行；声明确认的操作要求宿主确认标记，该标记不会来自插件回调。此层不授予存储/网络/文件/Shell 权限。

新增回归验证陈旧节点、捏造字段、禁用操作、未知选择、悬空关系、确认和有界输入；仅在 GitHub Actions 执行，结果待远程报告。当前未接入清单、QuickJS 页面实例、Compose 或市场入口，不能称为已交付插件界面。

## 第二个实现检查点

新增 API 9 的页面清单与 SDK 打包支持，页面 ID/标题及数量一致校验；旧 API 不接受页面声明。QuickJS 在启用时验证声明的回调存在，页面调用只允许使用不运行聊天生命周期的独立实例。

`ScriptPageSession` 每个打开页面一个引擎，保留本页状态且与聊天和其他页面分离。初始化、事件前、宿主操作前和返回视图后重新检查调用者提供的授权；关闭先中断执行再等待页面锁，处理并发初始化并释放原生调用。事件先经过当前视图校验再交 JS。模型推理仍只允许后台 Hook，页面没有新增隐式模型权限。

回归实际运行 QuickJS→页面→宿主存储→重新显示数据，检查中文/英文独立状态、撤销后零写入、过期事件拒绝，以及关闭等待中的原生调用时另一个页面仍可响应。SDK 验证打包后存在可调用页面。待远程执行结果，尚未接入 Compose、市场页面入口及生产存储撤销锁；这些仍是交付必需项。
