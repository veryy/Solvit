# Solvit 0.43.4（未发布）

此候选已停止发布。大字号授权按钮虽然通过交互测试，但实际截图显示工具名称和参数被挤出可视区域，人工验收未通过。正式Actions 38983612714已取消，未提供公开APK；标签保留历史，修复后使用新版本号。以下为当时准备的改动说明。

本轮集中打磨日常界面和操作反馈。

- 设置首页保留分组入口和当前状态；主题与动态配色收进独立外观页，返回后保留选择，语言继续放在靠后的位置。
- 等待队列默认收起；展开后可以编辑、移除或立即发送并打断。键盘弹出时，授权详情和队列内容分别滚动，操作按钮与输入区保留可用空间。
- 插件详情先展示状态和业务页面入口，权限按项展开；卸载与启用分开。插件页面打开或操作失败后可以就地重新打开，先清理旧会话，不自动重复刚才的写入。
- 工作区切换入口合并到顶部。创建或绑定过程中显示进度、禁止重复提交；失败保留名称和当前表单。绑定成功但目录读取失败时，保留已完成的绑定，不引导重复创建。关闭等待中的表单后继续显示后台进度。
- WebView 页面在就绪后接收状态，销毁页面时统一回收消息桥，保留原生生命周期压力与真实工作区回归记录。

版本为0.43.4/build87。正式发布由GitHub Actions把关：单元测试、Lint、固定签名、完整常规设备回归、1.5倍字体聊天、恢复与覆盖安装、stdio宿主清理、插件市场、公开搜索和实际Ubuntu运行检查全部通过后才提供下载。详细证据与历史失败见[UI阶段记录](ui-polish-stage.md)。
