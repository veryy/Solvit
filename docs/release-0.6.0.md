# Solvit 0.6.0

- 新增纯 TS Skills 技能库，首次启用提供 code-review 示例。支持 SKILL.md、单技能文本 ZIP 和 JSON 包导入，以及原生查看、删除和导出。
- 新增角色编辑和会话选择：角色提示词、插件绑定、技能选择按会话保存；新对话继承当前角色。删除角色后原会话需重新选择，避免自动扩大工具范围。
- Skills 每轮只注入允许技能的名称与描述，正文及文本资源按需读取；模型不能调用技能导入、删除、导出管理工具。allowed-tools 不会授予权限，脚本资源不执行。
- 宿主 API 3 开放只读 beforeModel Hook 和角色上下文；Hook 限制读取插件存储、执行时限及文本大小，停用/卸载会注销。
- 市场已部署 Skills 包与 API 3 目录；旧客户端继续只获得其支持的插件。下载包含 yaml 2.8.1 的 ISC 署名。
- GitHub Actions 验证 Android 单元与跨模块集成测试、Lint、APK、TS/市场测试、公网 HTTPS MCP，以及公网 Skills 下载校验、角色过滤和按需加载。

使用：先在插件页启用 Skills 并授予 storage，再点击聊天顶部“角色”进入技能库导入文件，创建角色并勾选插件和技能，将角色用于当前对话。详细格式见 docs/skills.md。

已完成真实 QuickJS、宿主存储、角色服务、Agent 工具循环和 SQLite 结算集成测试。真机文件选择与界面交互、真实模型采用技能的行为尚未验证。MCP 多服务器/更细工具绑定、其他 Hook、模型扩展、Root/Shell、附件、向量记忆等完整目标继续推进。

固定 APK 签名沿用 0.1.1 起的版本；0.1.0 的临时签名无法覆盖安装。
