# Solvit 0.21.3：记忆页面输入与操作

搜索框、筛选和清除按钮改为同一行；通用JS/TS页面渲染器为输入框分配剩余宽度，让键盘打开时操作按钮跟随输入框保持可见。提交时先保留输入内容，再隐藏键盘和清除焦点。业务页面仍由TS插件声明，记忆插件更新为1.3.1，数据格式不变。

[候选远程验证](https://github.com/veryy/Solvit/actions/runs/38269115386)实际报告271个单元、42个完整模拟器测试无失败/错误/跳过；原失败操作连续20次通过，包括输入、筛选、编辑、保存、关闭重开及删除。另一个异步导航测试误点禁用按钮的时序问题通过等待真实页面就绪修正，没有删除业务断言。临时诊断探针已清理；[完整诊断与失败证据](https://github.com/veryy/Solvit/blob/main/docs/memory-page-diagnosis-stage.md)保留原条件、对照和失败结果。正式标签重新验证清理后的源码再发布。

保留旧1.3.0插件下载文件；已安装的市场插件可更新到1.3.1，设置中的记忆管理页直接使用APK内置版本。稳定签名与原数据库迁移方式不变。

真实模型角色回答、真实流式/联网回答质量与真机交互仍未验收，不把模拟器或测试计数当作这些结果。没有运行本地Android或TS构建/测试。
