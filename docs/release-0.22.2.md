# Solvit 0.22.2：插件HTML界面、记忆图谱与多MCP

记忆1.4.0/API10与MCP1.1.0/API10携带离线HTML/CSS/JS业务页面。Android提供通用WebView、主题/语言、权限、确认、加密和资源清理；页面布局由插件绘制。旧API9控件树保持兼容。工作区、Skills等旧页面尚未全部转换。

- 记忆首页采用离线Cytoscape.js关系图，节点与连线来自实际记忆关系。支持拖动/缩放、搜索/筛选，点击节点查看来源、编辑与确认删除；后台任务和其他管理按需打开。
- MCP支持最多8个具名HTTPS Streamable HTTP服务器，各自配置、会话、启停及错误；插件HTML管理添加/编辑/测试/删除及标准HTTP mcpServers导入。凭据用Keystore加密保存，不回显已有令牌；页面禁截图，清除凭据需确认。
- 多个连接时工具必须指定服务器，同名远程工具明确路由；一方会话失效不影响另一方。有副作用的调用不自动重试，页面连接测试结束后关闭探测会话。
- 原版MCP1.0.0、记忆1.3.0/1.3.1仅在包哈希精确匹配时升级，保留事实、加密配置、启用及授权；用户修改包不覆盖、主动卸载不恢复。更早插件仍可从市场更新，不自动扩大旧授权。
- HTML交互在发送时阻止连续重入，用当前页面快照执行；过期事件拒绝，删除仍经过真实宿主确认。关闭、撤权、替换后消息桥与资源租约失效。

[干净候选运行38295011493](https://github.com/veryy/Solvit/actions/runs/38295011493)实际核对285个单元和44个模拟器测试，无失败、错误或跳过；Lint、APK、固定证书、覆盖安装、72 SDK/2市场及提交包一致性通过。首屏取证追加等待硬件帧提交，并加入实际PNG像素检查。修正后的[单用例38296564937](https://github.com/veryy/Solvit/actions/runs/38296564937)通过，已核对实际[图谱截图](screenshots/0.22.0/memory-html-graph-home.png)和[编辑详情截图](screenshots/0.22.0/memory-html-edited-detail.png)。正式发布还须通过标签的完整测试、模拟器、插件、公开搜索和签名门禁；下方构建链接提供实际发布结果。原图谱实体触摸、编辑保存、重开及取消/确认删除用例在[38293650208](https://github.com/veryy/Solvit/actions/runs/38293650208)通过；临时诊断已清理。[HTML阶段](plugin-html-stage.md)及[多MCP阶段](multi-mcp-stage.md)保留原失败和验证范围。

插件包由GitHub Actions生成，APK与市场使用相同字节；市场保留旧API包。采用Cytoscape.js 3.34.3及其MIT许可，没有复制Operit的LGPL页面代码。本地未运行Android/TS构建或测试。

真实模型的角色回答、可见流式、工具选择、第三方MCP接入和真实任务完成仍未验收，双HTTPS路由使用确定性Provider验证执行及回传。真机交互也未验收。本次不包含stdio、OAuth、动态远程函数注册、完整DSH重连机制，亦不代表聊天内核已达到用户要求。完整[后续路线](product-roadmap.md)保留。

模型设置打开协议/参数菜单前，在实际弹窗里结束文本编辑并收起键盘，保留输入。旧实现聚焦回归确认协议选择后配置名称仍为Focused=true；原保存及三次重开检查保留，最终验证以正式门禁为准。

0.22.0测试断言参数顺序错误、0.22.1设置点击与公开搜索门禁失败，均没有发布APK；失败标签保留、不覆盖历史。0.22.1两次公开搜索遇Bing人机验证/备用源错误，设置两次在相同模型字段点击处失败；本版本不把重跑称为根因修复，保留[诊断记录](model-settings-stability-stage.md)。市场API1..10及16种目录选中包、6个legacy包已经从公网逐字节核对。
