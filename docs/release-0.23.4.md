# Solvit 0.23.4：插件界面与可安装 Agent 策略

插件可自带 HTML/JS 页面：记忆关系图与后台任务、多 MCP 连接、Skills、工作目录和 xterm.js 交互终端由插件绘制。原生宿主处理权限、生命周期、存储、进程和系统能力。
