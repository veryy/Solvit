# Solvit 0.23.4：插件界面与可安装 Agent 策略

插件可自带 HTML/JS 页面：记忆关系图与后台任务、多 MCP 连接、Skills、工作目录和 xterm.js 交互终端由插件绘制。原生宿主处理权限、生命周期、存储、进程和系统能力。

API14 支持可安装 JS/TS Agent 步骤策略。“插件 → 市场 → JS Agent 步骤示例”安装后，先配置接管开关，再授权启用。默认关闭；同一时间只能选择一个。停用或卸载会取消并等待完整聊天轮次清理。Provider、消息协议、存储和权限校验仍由宿主服务负责。
