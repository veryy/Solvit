# Solvit 0.21.1：角色身份请求修正

选择自定义角色后，用当前角色的名称和设定替换模型设置自带的 Solvit 默认介绍，避免同一请求同时包含两套身份。另行填写的全局规则继续进入请求。旧版配置加载和新配置使用同一份内置默认介绍。

补充实际 HTTP 请求回归，覆盖默认角色、自定义角色、编辑设定、重新打开服务、显式全局规则和切回默认角色；模拟器回归通过设置页面应用角色后发送消息，再新建对话并检查 Provider 收到的角色与提示词。

[发布前远程验证](https://github.com/veryy/Solvit/actions/runs/38237983149)通过：实际报告271个单元和42个模拟器测试均无失败、错误或跳过，Lint、APK、固定签名及覆盖升级检查成功。修复前实际 HTTP 回归已复现默认介绍并存的问题；详细源码参考、失败→成功证据及验证范围见[角色故障复核](role-followup-stage.md)。正式发布由标签的完整远程门禁完成，不把测试响应当作真实模型身份回答验收。

保留稳定签名与已有配置、角色和聊天数据；卸载会删除本机数据。尚未在用户实际网关、真实模型和真机上验收角色回答，本次源码发现不代表已经确定用户症状的唯一原因。
