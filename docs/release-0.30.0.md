# Solvit 0.30.0：聊天附件与远程 Git 工作台

这版可以在聊天里添加图片、文本和代码文件，也补上了 Git 插件的 HTTPS 远程操作。build60 / 插件 API20。

## 聊天附件

- 通过系统文件选择契约选择多张图片、文本或代码文件；发送前卡片、移除、缩略图和独立预览。
- 支持仅附件发送；排队和直接打断保留附件快照，同一个对话框内展示附件。
- OpenAI兼容与Claude原生模型适配编码图片内容块，文本/代码正文作为用户资料发送；模型必须实际支持视觉才能读取图片。
- 私有 filesDir 保存原字节，SQLite10 保存引用；重开聊天、回复分支保留附件，删除原聊天保留分支副本。编辑旧用户消息时尚不会自动带回该消息的附件。
- 单条最多8项/20MiB，文本单项256KiB/UTF-8；PNG/JPEG/WebP/GIF受类型、解码和尺寸检查。PDF和其他文档处理尚未支持，界面明确拒绝。

## 远程 Git 工作台

- Git插件HTML/JS页面提供HTTPS仓库地址、分支、克隆、fetch、拉取/推送审阅、网络进度和取消。
- 仓库凭据通过宿主原生安全表单输入，Keystore加密保存；插件/模型不持有令牌。
- 拉取校验本地状态，支持实际非快进合并/冲突和双父提交；推送校验远程旧引用，不强制覆盖。
- 克隆先在私有暂存目录下载，保留Shell原工作目录及已有文件；安装中途恢复仍未完成。
- 文件树、编辑器、终端和Changes继续使用同一工作目录；AI Git工具目前仍只读。

## 验证和当前边界

发布前的[完整候选验收](https://github.com/veryy/Solvit/actions/runs/38512069795)已通过测试、Lint、APK、固定签名、模拟器和覆盖升级门禁；实际报告为 432 项单元和 57 项模拟器用例通过，零失败、错误和跳过。附件页面检查真实文件 URI、图片字节、文本正文、HTTP 请求和 SQLite 重开，系统选择器结果使用确定性夹具，未自动操作系统文件选择界面。正式发布还会运行插件 SDK、市场、公开搜索和 MCP/Skills 门禁，结果见下方构建链接。API20 市场已部署，并核对旧 API1–19 的目录保持兼容。
