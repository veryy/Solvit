# Solvit 0.15.1 修复版

- 默认角色也明确提供 Solvit 身份；自定义角色名称与指令每轮进入同一条系统消息。身份问题无需搜索角色信息，历史旧身份不能替代当前角色。
- 收到文本后逐 Unicode 字符显示，兼容网关一次返回整段内容的情况；停止可取消显示与请求。最终消息继续使用 Markdown。
- 语言设置移到底部，以单行入口打开选择弹窗。
- 插件市场和已安装列表采用自适应网格，手机每行两列，较宽屏幕可显示更多；名称和简介省略显示，点击查看详情并安装、启停、配置或卸载。移除试运行入口。
- 联网搜索 1.1.0 默认使用公开 Bing 搜索，启用后无需配置密钥。原始内置搜索插件随应用升级；用户自定义版本和已保存配置保留。

[远程 Android 验证通过](https://github.com/veryy/Solvit/actions/runs/38152202018)：单元测试、Lint、APK、签名、模拟器 UI 与旧版覆盖更新全部通过。[TypeScript 与免配置公网搜索验证通过](https://github.com/veryy/Solvit/actions/runs/38149487718)。实际模型遵循角色的程度和公网搜索可用性受模型服务及网络影响，不能用模拟响应宣称真机联动已验证。

构建流程将测试包编译、旧包下载与模拟器验证拆分，增加超时和失败日志采集，避免测试长期挂起而无法定位。
