# Solvit 0.9.1

- 修复兼容网关流式首帧 `finish_reason: ""` 导致正常聊天被误报失败的问题。空值表示尚未完成，继续接收后续文字与工具片段；真正断流和输出超限仍报错。已实际调用用户提供的 HTTPS 接口，验证普通聊天及工具调用返回。
- 桌面图标默认白底黑色线条；Android 13+ 支持的桌面可通过主题图标着色。应用内图标继续跟随 Material 主题。
- 聊天顶部移除角色按钮，角色管理保留在设置；侧栏加宽到屏幕的四分之三。
- 工作区整理为 Shell 和工作目录，支持显示真实目录、浏览文件和子目录、编辑文本；插件草稿放入目录的次级入口。
- 设置新增权限与执行方式：普通应用权限、Root 检测/请求、按插件选择执行身份。JS 插件不能自行提权；每次 Root 执行重新核验 UID 0，模式变化停止旧任务并使旧确认失效。
- 修复 MCP 取消时 HTTP 连接关闭与协程取消竞争导致取消通知偶发漏发。

保持固定签名，可以覆盖安装 0.7.0 及后续同签名版本。卸载会删除数据，升级应直接覆盖安装。

Root 真机、不同 su 管理器、Shizuku、无障碍、PTY 持久终端、Linux 环境及 SSH/SFTP 仍待实现或验证。实际 HTTPS 测试不等同于手机上的完整真实模型交互验证。
