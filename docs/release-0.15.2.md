# Solvit 0.15.2：上下文与流式显示修复

- 角色改为有名称和来源的提示段，身份指令只注入一次；当前角色设定明确优先于全局默认身份和历史自我介绍。
- 模型事件接收与回复显示分离。文本和思考片段按回合顺序排队，工具状态及时更新；相邻小片段合并，按帧逐步显示，大段回复自动加快追赶。
- 最终回复提前入库时，显示继续完成当前进度，避免突然跳出整段全文；停止同时取消接收与展示。
- 展示缓冲有大小和事件数量限制，避免无界累积。显示速度不会改变服务端真实流式行为；网关缓冲和模型思考延迟仍需要请求时间诊断。
- 本地已拉取 DSH、Operit、AutoGLM、ZCode、智谱编码插件及 Claude Code 公开仓库，锁定版本并加入后续各阶段的源码参考规则。

版本号 0.15.2，版本码 21。采用既有稳定签名，覆盖更新保持配置与聊天记录。

身份重复和接收阻塞分别通过两次远程回归复现，见 [源码参考与证据](upstream-reference.md)。[修复后的远程验证通过](https://github.com/veryy/Solvit/actions/runs/38158456320)：153 个单元测试全部通过，Lint、APK、固定签名和模拟器界面及覆盖升级检查通过。发布流程还会验证 TS 插件及公网服务后上传 APK。此版本不宣称已经完成真实模型角色遵循、真机体验或全部上下文管理。
