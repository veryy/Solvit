# Solvit 0.7.0

这次优先修复设置、更新、安装和插件使用体验。

- 设置按模型配置、角色与 Skills、插件、外观、配置备份、应用更新和关于分组。支持跟随系统/浅色/深色主题和动态配色开关。
- 模型配置可从 API 默认 /models 接口或独立 JSON 订阅地址获取名称，支持搜索和选择；也可手动填写。订阅 token 加密保存。
- 手动检查更新移入设置；启动时顶部加载检查，没有新版时隐藏卡片。
- 版本说明在应用内查看；APK 在应用内后台下载，显示进度、支持取消和重新下载，进程重启后恢复任务。下载后校验摘要、包名、证书和版本号，再交给 Android 系统安装程序。
- 配置可使用密码加密导出和导入，包含模型/API Key、列表地址、提示词、角色及外观。API Key 无法解密时保留模型地址和提示词，不重置所有配置。
- 时间插件 1.1.0 每轮提供最新时间上下文；0.7.0 宿主提供 Android 真实时区。角色限制、停用和卸载继续有效。原始离线时间包自动升级并保留启用状态，修改过的包不会被替换。
- 插件页显示 AI 可发现的工具数量；Skills 1.0.2 修复大量中文技能目录超出上下文限制的问题。市场保留旧版本，旧客户端仍可下载兼容时间插件。

## 安装与数据迁移

实际检查发现旧 APK 签名不一致，之前“0.1.1 起固定签名”的说明不准确。0.7.0 明确指定 CI 签名文件，并强制校验证书 SHA-256：

`f076abf86de542063f8655abf9021cb88b642ab9b664cafc46c0f16b4303bcc3`

0.6.0 及以前的已发布 APK 私钥未保留，无法生成能覆盖它们的新版。**迁移前先记录旧版 API 地址、模型名、密钥和提示词，并导出需要的 Skills；不要直接卸载有重要数据的旧版。** 此版本的配置备份功能无法追溯恢复此前删除的数据。以后相同签名且版本号更高的覆盖更新保留应用数据；卸载会删除数据，需预先导出备份再恢复。

配置备份暂不包含聊天记录、插件包、插件密钥和插件记忆。聊天 SQLite 数据库尚无导出入口。正常更新保留这些应用内数据。
