# Solvit 0.21.0：工作区执行记录与文件审阅

新增持久执行记录、文件变更审阅及结构化工具失败详情。正式 APK 由标签的完整远程门禁通过后自动发布。

工作区工具执行时逐步保存模型步骤、待授权调用、开始边界及工具返回结果。记录绑定原对话、角色和工作区，重开聊天后仍能查看；进程中断只恢复已记录事实，不自动重跑命令。未拿到结果的操作明确显示未知。

执行记录显示在同一条助手回复内，默认折叠。文件变更比较首次授权前与最近工具返回后的持久观察，可展开查看前后文本片段、文件长度和内容哈希。打开审阅不会重新执行工具。已配置密钥会脱敏，扫描不完整、二进制、超限、截断和未观察到后续状态均明确提示。

文件写入返回实际写前/写后证据；Shell 返回实际工作目录、任务状态、输出和退出码。文件工具失败提供固定错误分类和下一步信息。每步工作区指引要求查询任务结束状态、失败后修复和重新验证，不能把启动成功或写文件成功当作项目验证通过。

扫描最多64个文件、512个目录项、12层、总读取2MiB，每文件最多256KiB；持久预览最多512字节。当前为有界目录观察和前后片段，尚非Git原子快照或完整逐行diff，外部并发进程仍可能改动文件。

保留稳定签名、已有配置及聊天迁移；SQLite7→8新增执行日志。0.7.0及之后相同签名版本可覆盖升级；卸载会删除本机数据。

发布前[Android验证](https://github.com/veryy/Solvit/actions/runs/38213587946)已全成功：测试、Lint、APK、固定签名及覆盖升级，包含实际Android工作区失败修复与重开聊天审阅；开始检查点后的授权撤销也已回归验证，不继续执行或扫描。正式标签门禁和发布结果由Release下方工作流链接提供。

交互终端首次输出检查曾出现一次8秒超时，本轮相同断言通过；未确定原因，保留原生会话、界面节点与截图诊断，不宣称已经修复该偶发问题。

完整任务使用脚本模型决策，检查真实QuickJS、文件、Shell失败退出码7→修复→0和SQLite重开事实；Android模拟器已验证同一任务及聊天审阅。尚未进行真机或真实模型自主任务验收，提示指引不保证模型遵守。手机控制、项目规则自动装载、完整文件diff及可替换JS Agent仍是后续工作。
