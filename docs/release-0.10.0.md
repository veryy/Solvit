# Solvit 0.10.0

继续包含 0.9.1 的聊天修复：兼容网关首个流式分片的空 `finish_reason`，HTTP 200 不会再因空结束原因被误判失败。此前已使用用户提供的 HTTPS 接口验证普通回复、工具请求与工具结果回传后的回复。

## 交互式终端

- 工作区 → Shell 新增“交互终端”，可发送命令或交互回答、Ctrl-C 中断、关闭终端，也能查看 AI 插件创建的终端。
- 新增独立 Kotlin 宿主插件 `builtin.pty` 和 JS/TS 插件“交互式终端” `dev.solvit.terminal`。在插件页启用并授予工作区和 Shell 权限后，AI 可打开终端、发送输入、读取状态、打断及关闭。
- 使用真实 Android PTY；同一进程保留 `cd`、导出的环境变量和交互提示。终端按插件、角色、工作区和 Shell 分开；权限确认绑定完整输入，停用插件或切换执行身份时关闭相关终端。
- 输出有界保存；UTF-8 分片连续解码。最多 8 个活动终端、16 条历史，每条保留最近 65536 个字符。
- 市场新增 API 5 包；API 1–4 客户端继续得到兼容目录。

## 使用

手动操作：聊天 → 工作区 → Shell → 交互终端。命令输入后点“发送输入”，再次输入时继续使用同一终端。

AI 操作：启用“工作区与 Shell”及“交互式终端”；先获取 Shell ID，再打开终端。AI 的 `terminal_input` 工具必须自行在文本末尾加换行，之后读取 `terminal_status` 获取输出。每次操作遵守原有角色与工具授权策略。

## 边界

当前交互 PTY 使用普通应用身份。原有 Root 普通命令工具仍可使用；选择 Root 后交互 PTY 会明确拒绝启动，不会静默降级。Root PTY、Shizuku、Ubuntu/Linux 发行版、SSH/SFTP 和完整 VT 屏幕仍未交付；本版界面显示终端文本，不支持全屏 TUI 的屏幕布局。

终端进程与输出随应用进程结束，不会跨重启恢复；工作区目录、绑定与 Shell 名称保留。终端拥有应用 UID 的文件及网络权限，工作目录不是操作系统沙箱。关闭会终止前台进程并向会话发送挂断；不能保证回收主动脱离终端的守护进程。

APK 使用 0.7.0 起的同一固定证书，支持覆盖更新并保留配置与聊天记录。发布流程要求单元测试、Android 35 模拟器 PTY/JS/界面/覆盖更新测试、TS/市场测试、Lint、APK 和签名校验全部通过。尚未完成真机、真实 Root 管理器，以及真实模型在 Android 上完整使用 PTY 的联动验证。
