# Solvit 0.43.5

这轮集中打磨聊天、设置、插件管理和工作区反馈。0.43.4候选因截图验收未通过而未发布，原标签保留。

- 工具授权保留在对话中，始终显示真实工具名称。默认收起详情，展开时收起键盘，查看完整参数、执行身份和“免询问”的作用范围；操作按钮短文案保留完整无障碍说明。
- 等待队列默认收起，展开后编辑、移除或立即发送并打断；输入框与顶部栏按实际剩余高度布局。
- 设置按组显示，主题与动态配色进入独立外观页，语言留在靠后位置。
- 插件详情突出状态和页面入口，权限按项展开，卸载与启用分开。页面失败可就地重新打开，先清理旧会话，不重复已发出的写入。
- 工作区切换合并到顶部。创建或绑定显示进度、防止重复提交，失败保留名称；关闭等待表单仍显示后台进度，绑定成功但目录读取失败时保留绑定。
- 插件市场区分已安装版本和目录版本；旧目录不能覆盖较新的本地插件。官方记忆插件可保留既有数据、启用状态和权限升级，用户改过的包保留原样。
- 记忆关系图采用组件现有的防重叠分圈布局，保留拖动、缩放、筛选、编辑和删除；长标签按真实尺寸参与布局。
- WebView就绪后才接收状态，由页面销毁统一回收消息桥；保留原生生命周期诊断与范围限制。

固定签名与数据格式保留，正常覆盖安装保留数据，卸载仍会删除本地数据。版本0.43.5/build88。候选生产构建617项单元、Lint与固定签名通过，生产APK上的1.5倍字体完整聊天流程和实际截图已核对。正式发布要求设备回归、大字号、恢复/覆盖安装、插件、公开搜索与Ubuntu检查全部通过，结果见页尾Actions及阶段记录。
