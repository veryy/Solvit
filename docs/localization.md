# 界面语言

设置 → 语言：中文（默认）、English、日本語、한국어、Español、Français。选择立即生效，保存到本机，配置备份包含语言字段；旧备份没有该字段时使用中文。

界面翻译离线存储在 `app/src/main/assets/ui-locales.json`，不上传用户内容，也不需要翻译 API。聊天消息、角色提示词、代码、原始工具/模型结果、第三方插件说明和更新说明保持原文。语言选择不自动修改模型提示词或强制模型回复语言。

新增界面文案使用 `UiText`/`UiIcon`；动态界面文案的目录键用 `{0}`、`{1}` 等占位符，六种语言必须保留相同占位符。用户定义的名称、消息和原始数据使用普通 `Text`；固定界面片段与这些数据组合时可用 `uiString`，避免翻译用户内容。需要新增语言时同步修改 `uiLanguages`、目录及测试。

远程测试检查六种语言覆盖和占位符一致性；Android 界面测试检查切换、立即刷新和重启后的保留。
