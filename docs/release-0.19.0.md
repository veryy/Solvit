# Solvit 0.19.0：后台自动记忆与来源管理

本版增加默认关闭的后台自动记忆、来源管理与任务状态。

已发布：[下载 APK](https://github.com/veryy/Solvit/releases/download/v0.19.0/solvit-debug.apk)。[正式标签构建](https://github.com/veryy/Solvit/actions/runs/38190322667) 的全部发布门禁成功；213 个单元和 33 个模拟器测试无失败、错误或跳过。APK 为 22,835,567 字节，SHA-256 `48f2c8e32296700116ba0b6c88820ed8f1996035495f8ca72729866fac29caed`。

- 记忆插件 1.2.0 增加默认关闭的后台自动保存。启用后，只处理之后完整结束的聊天回合；中断、失败及此前历史不自动加入。
- 每次抽取最多一次模型调用，使用原回合模型配置，有输入、输出及执行期限限制；无需等待前台聊天结束。
- 保存用户明确提供的资料及原文引用，按角色检索。引用校验不能保证模型抽取语义正确，请查看并修正重要资料。
- 设置中的记忆管理支持查看、编辑、删除和来源；人工修改不会被后台抽取覆盖。任务页显示状态、失败分类、停止及确认后的有限重试。
- 支持确认清理成功/跳过任务及已退休的来源去重记录，保留事实、聊天与失败/活动任务。
- 原生与 TS 使用原子比较写入，执行中权限撤销、插件停用或配置变化会阻止后台写入。
- Claude 原生工具回合中，动态插件资料追加到真实消息尾部；保存请求投影，重开后重放，保留签名前缀检查。签名回合中的工具列表变化尚不支持。
- 线上市场 API 8 提供记忆 1.2.0；旧客户端继续获取兼容版本。旧配置、聊天、记忆命名空间和固定 APK 签名保留，SQLite 迁移到版本 7。

使用：打开插件页，更新记忆插件并确认 storage/model 权限；角色需允许记忆插件。在插件配置中打开自动保存。后台抽取会产生额外模型费用；退出或被系统终止后不保证继续运行。失败任务不会自动重放，可在任务页查看和有限重试。

已有升级用户的记忆插件不会被静默替换或自动扩大权限；人工管理自己的记忆可以在插件停用时使用。当前管理界面由 Kotlin 提供，插件自带页面接口是下一阶段，见 [插件界面计划](plugin-ui-plan.md)。

包含客户端 API 8 切换和本版本号的[候选构建](https://github.com/veryy/Solvit/actions/runs/38189402281) 已通过 213 个单元测试、33 个模拟器测试、Lint、APK、固定签名和覆盖升级；XML 报告无失败、错误或跳过。新增回归通过真实市场请求和安装流程验证记忆 1.2.0 安装后默认停用、没有自动授权。插件及联网搜索由标签发布门禁另行验证。真实模型抽取质量、真实 Claude 账户和真机行为尚未验收。向量检索、工作区完整执行验证和手机操作继续推进。
