另核对 DSH `packages/llm/token-meter/src/estimate.ts`（固定字符密度、消息结构和工具定义计价）、`route-pricing.ts`（按实际路由的投影定价）及 `turn-usage.ts`（Provider 实测 usage 单独核验）。Solvit 暂采用更保守的 UTF-8 估计，保留 `ContextTokenMeter` 的替换接口，并由 Provider 返回输出预留；不复制 DSH 的固定每四字符一 Token 去宣称中文或自定义模型的精确用量。

## 当前实现

- `ContextBudgetPlanner` 是独立注册服务，可替换计量与区域规划。当前是保守 UTF-8 字节估计，计入身份/规则、Hook 资料、历史、原始转录、工具定义和消息开销；不是 Provider 实测 usage 或特定模型分词器。默认 65536 是本机预算，不能据此推断模型真实容量。按服务容量在模型配置的折叠“上下文管理”中设置窗口、输出预留、余量和自动摘要。
- Provider 声明输出预留，路由服务转发该契约。Claude 包括默认 8192 及未结束原生工具回合保留的参数；兼容协议发送最大输出限制，摘要请求独立设置最多 1024。Provider 的实际 usage 后续单独接入，不能由估计值推导。
- 按 [OpenAI 官方参数定义](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 核对输出字段：`max_tokens` 已弃用且不兼容 o 系列。兼容 Provider 可声明选择 `max_tokens` 或 `max_completion_tokens`；自动模式仅按官方服务地址选择，其余服务保留兼容字段，不按模型名称猜测。每次请求只发送一个限制字段，摘要沿用选择。
- 每步在 Hook/工具组装后准备预算。保持系统规则和当前用户回合，不拆工具调用/结果；只有完整旧回合参与摘要。仅在超出预算时，工具输出在模型投影中保留头尾并标记裁剪，原聊天及工具展示保留完整输出。
- 未结束的原生工具回合带请求摘要值时，保护其原始消息前缀：不摘要旧范围或裁剪已用于原生请求的早期工具结果，仅允许裁剪最新工具回传。仍超预算则明确失败，避免改写签名所依赖的上下文。完整动态 Hook 与原生签名的真实模型组合验收仍待补充。
- 自动摘要额外调用当前路由模型，无工具、无 Hook，最多八批、总期限 60 秒；每批输入经过同一计量，按完整旧回合分组。摘要必须完整结束、缩小上下文且使最终请求进入预算，否则报错并保留原状态。不能压缩的当前输入或工具定义明确报错，不静默删除身份、工具或当前任务。
- SQLite 版本 6 新增摘要表。原聊天不删除；摘要带覆盖边界、原记录摘要值、提供者和模型及估计前后大小。提交在单个事务中检查原记录前缀及上一版摘要。重启后复用；聊天分支使用新消息 ID 并重新生成摘要；删除聊天级联删除摘要。
- 最近请求诊断记录预算元数据，不记录摘要正文；用户可主动打开独立历史摘要弹窗。模型配置加密保存及配置备份包含预算，旧配置缺少字段时使用兼容默认值，并容纳已保存的有效显式输出上限。
