# Solvit 0.11.0

## 聊天展示

- 同一轮的工具调用、工具结果与模型最终回复放在同一个助手气泡中；默认只显示工具名称，点击后展开参数、状态和实际结果。
- 回答使用原生 Compose Markdown 富文本渲染，不显示 Markdown 标记；思考过程独立保存并默认折叠。思考文本不会进入下一轮模型上下文。
- 助手消息左对齐、用户消息右对齐，气泡使用较小圆角。
- 顶部右侧改为设置按钮；新建对话保留在侧栏。

## 按需工作区

新对话默认没有工作区，只进行聊天。已保存模型配置后，空白页隐藏“配置你的模型”，显示“新建工作区”。创建或绑定后才出现工作区入口，创建时包含 Shell 1。没有工作区时不向模型提供目录、Shell 和插件草稿操作工具；时间、记忆等插件仍可使用。

## 当前时间

时间插件升级至 1.2.0，明确区分同一瞬间的本地时间和 UTC，并提供可读日期、星期与时区偏移。询问当前时间时要求调用实时工具。设备时间取决于系统时钟，模型是否发起调用仍取决于其工具调用能力；展开详情可检查实际返回值。

## 验证与边界

发布流程要求单元测试、Lint、APK、固定签名、TS/市场和 Android 35 模拟器检查全部成功，包含折叠工具/思考富文本、按需创建工作区、真实 PTY、JS 桥接、键盘布局及覆盖更新保留数据。

沿用 0.7.0 起的固定证书。尚未完成真机、真实 Root 管理器和真实模型与 Android 工具的完整联动测试。保留 0.9.1 空 finish_reason 流式分片兼容修复；交互 PTY 的限制见 0.10.0 说明。
