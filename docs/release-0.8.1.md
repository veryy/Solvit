# Solvit 0.8.1

- 聊天和模型列表请求失败可在底部“查看详细信息”，包含 HTTP 状态、地址、请求 ID 与服务端响应；隐藏已知密钥和订阅参数。404 报告实际响应，避免直接断言服务不支持。
- 设置、插件、角色与工作区页面统一系统栏与底部避让。侧栏缩为半屏，设置入口移到底部；移除聊天和侧栏底部提示。
- 聊天输入卡片悬浮，首次打开自动聚焦与弹出键盘。键盘避让放在卡片外层；打开侧栏或能力页面时收起键盘。
- Shell 点击运行后收起键盘，留出结果显示空间。
- 原创纯线条放射图标，六向对称、中心扩散；支持 Android 自适应遮罩与单色主题图标。
- 每个聊天持久绑定一个工作区，工作区可关联多个聊天并保存多个 Shell 会话。支持文本文件编辑和以应用身份执行非交互式 Shell 命令。
- API 4 的“工作区与 Shell”“插件开发”为独立 JS/TS 插件；工具调用绑定当前聊天、工作区和确认参数。
- AI 可生成并校验普通 JS 插件草稿，用户查看代码与权限后安装；安装保持停用，必须单独启用。工作区文件变更后摘要校验阻止安装旧审阅版本。

TS 源码仍需通过 SDK 在开发工具或 GitHub Actions 中编译；应用内没有 TS 编译器。Shell 尚不支持 PTY 交互输入、持久环境、Root、Shizuku、Linux 发行版、SSH/SFTP，任务与输出目前不跨进程恢复。Shell 权限覆盖本应用 UID 的文件和网络，不是目录沙箱。配置备份不包含工作区和聊天记录。

保持 0.7.0 的固定签名；远程 Android 35 模拟器已实际安装公开的 0.7.0 APK、写入加密配置及聊天记录，再覆盖更新到新版，确认 API Key 可解密、模型配置与原聊天均保留。0.6.0 及更早版本签名不同；卸载会清除原数据。尚未进行真机和真实模型测试。
