# Solvit 0.18.0：上下文预算与可查看历史摘要

- 模型配置新增折叠的“上下文管理”：窗口、输出预留、压缩余量和自动摘要。默认窗口为本机预算，请按服务实际容量设置。
- 每次模型请求计入规则、资料、历史、工具定义和原始转录。使用保守 UTF-8 字节估计，并非服务商实际 Token 用量；Provider 声明实际输出预留。
- 兼容协议可选择服务支持的输出上限参数，自动模式区分 OpenAI 官方地址与其他兼容服务；摘要使用同样的参数选择。
- 超出预算时先裁剪模型上下文中的较大工具输出，保留头尾和截断标记。能放下时保留完整输出；聊天展示及原始记录保持完整。
- 完整旧回合自动生成摘要，保留当前任务和工具调用/结果配对。摘要额外调用当前模型，最多八批、总期限 60 秒；聊天显示批次进度，可停止。
- SQLite 持久保存摘要并核对原记录边界及上一版本；重启复用。摘要失败、未缩小到预算内或提交时记录变化均报错，保留原聊天及已保存摘要。
- 设置的“最近请求诊断”显示预算估计，可主动查看最近请求所在对话的历史摘要。诊断元数据不保存摘要正文、密钥或工具参数。
- 预算配置进入加密模型配置及备份。旧配置、角色、聊天和固定 APK 签名保持迁移兼容；新数据库版本为 6，聊天分支按新的消息 ID 重新生成摘要。

当前为发布候选，全部远程门禁通过后发布 APK。验证证据见 [上下文阶段记录](context-budget-stage.md)。

尚未验证真机性能和真实模型摘要质量。估计不是模型专用分词器或实际 usage；后台长期记忆抽取、向量检索及完整工作区任务与步骤日志继续推进。不能整体压缩的当前输入、单个过大旧回合或工具定义会明确报错，需要缩小输入或调整窗口，不静默删除规则或当前任务。
