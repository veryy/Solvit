# 联网搜索

联网搜索插件 1.2.0 在 API 6 宿主上默认访问公开搜索网页，安装并启用后无需填写 API Key 或服务地址。角色使用自定义插件白名单时，需要允许 `dev.solvit.web-search`；实际工具调用仍经过用户授权。

默认通过匿名浏览器观察 Bing 搜索页面，失败再尝试 DuckDuckGo，最后使用基本关键词过滤的 Bing RSS 备选。返回标题、摘要和来源链接；`read_page` 优先读取浏览器 DOM 正文，失败再静态读取。首页重定向、空结果不会当作搜索成功，结果区链接优先于普通页面链接。

公共引擎可能受网络、验证码或限流影响，失败会明确说明，不能保证每次都能获得结果。默认搜索和正文读取不发送模型或插件配置中的密钥。浏览器不提供原生 JS 接口，不访问本地文件；观察、下载和结果大小均有界，停止时回收资源。

保留可选 Tavily、SearXNG 和智谱接入，只有主动选择这些后端时才需要配置。旧版用户明确保存的后端不会被覆盖。已安装的官方 1.0/1.1 包升级保留配置和启用状态；市场仍向 API 2–5 的旧客户端提供 1.1.0 包。

参考 Operit 网页访问和多平台搜索、DSH 独立获取服务，将 Android 网页观察与 TS 搜索策略分开。具体文件、适配和验证边界见 [阶段说明](browser-search-stage.md)。网页内容作为外部数据，不覆盖角色与用户指令。

公网 Chromium 检查和 Android WebView 离线 DOM 检查分别验证来源链及原生观察服务；真实模型最终引用、真机网络和更广泛的相关性仍需验收。
