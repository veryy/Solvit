# Solvit 0.38.0：导入进度、取消和暂存清理

在工作区确认导入后，插件页面显示实际写入字节和准备、写入、同步、校验、发布阶段，并可请求取消。字节达到100%不等于已完成；最终以任务结果为准。取消完成前等待清理，之后仍保留选择，重新审阅即可重试。已发布的完整文件遇到晚取消仍显示成功。

替换中取消会恢复原文件。若Shell抢先创建同名文件，保留双方，并明确显示原文件备份路径，避免把未恢复的情况只显示成普通取消。关闭页面会取消并等待任务清理，不转为后台长期导入。

启动时异步回收已登记工作区内保留格式的孤立`.solvit-import-*.partial`普通文件，保护本进程仍在使用的暂存。不跟随符号链接、不进入.git，也不删除正常文件或solvit-backup原文件备份。每工作区单次扫描限制20000项和32层；这不是全局容量配额。

系统强杀恰好发生在旧文件移走后时，原文件备份保留，跨进程自动恢复原名字仍需后续事务日志和进程死亡验收。同步磁盘和原生调用不能保证瞬时打断。系统选择器读取阶段不包含在工作区写入进度内。

工作区插件1.9.0/API26，Git1.2.5/API20；旧API25宿主继续选择工作区1.8.0。历史下载保持原字节，升级保留项目规则与授权，修改过的插件和卸载选择不覆盖。Linux开发环境继续保留，见[Python/Node/Java指南](linux-environment.md)。

验证状态请以[完整阶段记录](workspace-import-transfer-stage.md)和正式Actions为准；当前仍在候选验证，公开最新版是0.37.0。ARM64真机、真实模型完整任务、真实系统picker手指操作和本地stdio MCP尚未验收。屏幕操控暂缓，容量管理、跨进程事务恢复、Git克隆中断恢复和真实GitHub账号插件写入继续保留在路线中。
