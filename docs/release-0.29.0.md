# Solvit 0.29.0：Git 工作区（候选，尚未发布）

工作区增加 Git 入口，业务页面由插件自带 HTML/JS 绘制。文件树、CodeMirror 预览与编辑、Shell 和 Git 操作使用当前对话绑定的同一个目录。

- 显式初始化本地仓库；查看真实工作树与暂存区 Changes、分页状态和完整差异。
- 差异完整加载后审阅暂存或取消暂存；写操作须用户确认，取消不修改仓库。
- 提交只采用审阅的暂存区，保留未暂存和未跟踪文件；填写提交说明、作者、邮箱，并查看提交历史。
- 宿主复核文件内容、可执行位、HEAD、分支与索引版本；审阅后文件或索引变化时拒绝旧操作。
- 同页“文件管理”复用文件树和 CodeMirror，保留完整文本预览、256KiB UTF-8 编辑、目录操作与保存冲突检查。
- Git 插件提供 AI 只读状态、差异及历史工具。启用插件并允许当前角色使用后，调用经过对话绑定、权限及参数检查；大差异分块读取并核对摘要。
- API19 市场提供 Git 1.1.1，公网下载与 APK 内包一致；API1–18 目录响应及已有插件包保持原字节。Git 默认停用，人工工作区页面可独立使用。

使用路径：聊天中绑定或创建工作区 → 打开工作区 → Git。初次使用需要明确初始化；已有仓库直接查看 Changes。“文件管理”可查看和编辑同一目录。供 AI 使用时，在插件设置中启用 Git，并检查角色的插件允许范围。

原生 Git 使用 JGit，Android 26/35 已验证真实仓库和服务生命周期。最新 a7ef7b3 的 406 项单元测试报告与两项 Git 实际页面测试已核对；差异框高度/末尾滚动、完整差异、取消/确认暂存、只提交审阅索引、文件预览与同目录 Shell 均通过。Lint、APK 构建及固定签名通过；完整模拟器回归、覆盖升级和正式发布门禁仍待结果。以上功能说明不能替代最终验收，当前公开版本仍为 0.28.0。过程与失败证据见 [Git 阶段记录](workspace-git-stage.md)。

当前 AI Git 工具只读；AI 暂存/提交、GitHub 克隆/拉取/推送、凭据管理与冲突处理继续开发。暂存保存原始文件字节，不支持 LFS 自动过滤器、共享工作树或外部 Git 对象目录。文本/代码预览和编辑保留当前限制，图片/PDF等二进制预览尚未实现。真实模型自主项目任务、宽屏实际布局和真机体验尚未验收。
