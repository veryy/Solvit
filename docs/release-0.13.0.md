# Solvit 0.13.0

- 角色应用后在设置里明确提示下一条消息生效，新对话继承当前角色。角色、通用提示词和插件上下文合并为一条系统消息，改善部分兼容网关只保留第一条系统消息时的角色丢失。
- 调整工具使用规则：代码说明和示例优先直接回答，只在用户任务需要时调用相关工具。角色插件白名单继续强制执行；模型本身的工具选择仍可能出错。
- 增加“允许且不再询问”，跨重启记住同一角色和工具的授权。插件代码、权限、执行模式或角色配置变化后重新询问；设置 → 权限与执行方式可以清除授权。
- 生成中直接显示每段文字，完成后使用富文本 Markdown 渲染。聊天列表等待布局后跟随回复底部，长回复和键盘弹起时也保持末尾可见；手动拖动阅读历史时停止跟随。
- 交互终端采用深色 ANSI 字符屏幕，支持光标、颜色、清屏、回车覆盖、备用屏幕、有限滚动历史和直接按键；提供方向键、Esc、Tab、Enter、退格及 Ctrl-D。保留命令输入和 Ctrl-C，仍使用真实 Android PTY。当前是基础 ANSI 支持，未验证所有全屏 TUI/编辑器。
- 新增独立 TS “联网搜索”插件，支持 Tavily、SearXNG 和智谱搜索，以及静态网页文字读取。返回可引用来源，工具详情在同一聊天气泡折叠展示；需要自己的搜索服务配置，默认停用。

尚未进行真机或真实搜索账号与模型的完整联动验证。
