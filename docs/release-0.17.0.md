# Solvit 0.17.0：自动读取已保存的记忆

- 本地记忆插件 1.1.0 会在聊天前自动检索相关记录、补充已保存的用户画像，并带记录 ID、来源和更新时间。模型无需先调用检索工具。
- 每个模型步骤重新读取插件上下文；工具保存或删除记忆后，下一步骤看到最新结果，不累积旧提示段。
- 插件配置新增原生“自动将相关记忆用于聊天”开关。关闭时不读取记忆存储；停用或角色未绑定时也不注入。
- API 7 只将声明为非密钥的配置提供给上下文 Hook，保留禁止密钥读取、写入、联网及工具执行的门禁；公开资料不会改变原生授权。
- 自动检索贡献最多六条，长记录明确标记截断。优化 BM25 的重复语料扫描，避免每一步反复执行昂贵检索。
- 已安装的记忆 1.0.0 不静默升级：在市场更新到 1.1.0、查看说明并重新启用。旧客户端继续获得 1.0.0。已有记忆格式与记录保持兼容。

这是发布候选说明，远程 Android/TS/市场与模拟器检查通过后再发布固定签名 APK。验证结果见 [阶段记录](memory-context-stage.md)。版本码 24，保留既有角色、流式、搜索与请求诊断。

自动检索会将相关已保存资料提供给当前模型；保存、修改、删除及批量抽取仍通过工具授权。后台自动提取、全请求 Token 预算、自动摘要、向量检索和记忆管理页继续实现，不将记忆贡献长度上限当作完整上下文管理。尚未进行真机或真实模型的完整记忆联动验收。
