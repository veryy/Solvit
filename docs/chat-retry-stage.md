## 实现

- ChatService声明重试能力；DefaultChatService持有原执行互斥锁后重新读取最新历史，核对传入回复ID、未完成状态与原用户消息，拒绝过期或成功回复重试。
- 不重复保存用户消息，不重新导入附件；从私有原文件重建图片/文本模型请求。所有旧失败助手/工具记录排除于模型上下文。
- 新回复在同一聊天气泡实时显示，旧失败内容默认折叠；原执行事实与文件差异仍可展开查看。配置读取门禁、授权、角色、工作区和排队机制保留。
- SQLite11事务迁移执行表：一条用户消息可有多个顺序执行尝试，同对话仍只能有一个RUNNING记录；保留旧事件、文件引用和不可变文件字节，已完成的用户回合拒绝再次执行。
- 重试后原等待队列保持暂停，用户可以选择继续。重试会重新请求模型，工具可能再次执行；不宣称操作幂等或自动重试。
