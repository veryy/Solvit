和 [38370149931](https://github.com/veryy/Solvit/actions/runs/38370149931) 保留真实 DOM 证据：

还需核对匿名访问：App 的 CookieManager 禁用 Cookie，而此前远程验收默认保留会话。
对照 [38370504424](https://github.com/veryy/Solvit/actions/runs/38370504424) 将每次访问改为独立实例，
所有请求移除 Cookie，保留原查询、500ms 观察等待和 7000ms 超时。桌面主入口三个查询全部有真实结果；
手机主入口和区域入口三个查询都有真实结果，旧观察器漏掉手机标题标记。
验收器改为 Pixel 7 手机视口、独立实例与不发送 Cookie，贴近现有 Android 匿名 WebView；
仍保留三个查询、前五官方来源、正文和独立获取的最新版本断言，以及主入口故障时必须得到区域 DOM 结果的断言。
这是浏览器近似环境，不能代替真机联网验收。完整门禁结果待远程运行，当前不能声称发布通过。

修复后的公开搜索运行 [38370945128](https://github.com/veryy/Solvit/actions/runs/38370945128) 三个查询及区域故障回退均通过，来源正文包括独立验证的 Kotlin 2.4.21。正式 0.23.2 运行的搜索也通过，但 Skills 校验把 API3 目录旧包与根目录 API11 新包比较而失败。实际 HTTPS 目录和下载哈希确认旧 1.0.2 与新 1.1.1 均正确；改为分别校验历史包和当前 manifest 声明的 API/版本，保留加载及角色筛选断言。不是修改线上包去覆盖历史。

0.23.3 的实际报告为335单元、48模拟器无失败/错误/跳过，固定签名与APK通过；两个搜索尝试正常三查询全部通过，区域入口却返回无正文/无结果的首页，未发布。停止重复重跑。对照 [38374181996](https://github.com/veryy/Solvit/actions/runs/38374181996) 保持匿名手机环境与全部查询，仅比较正常区域、国际搜索、市场、语言参数；国际模式三个查询均返回真实官方来源链接。所有模式在该运行也可用，所以不能断言参数彻底解决服务波动。产品增加有界的国际区域备用模式；查询不改写、等待/超时不延长、首页过滤不放宽。门禁仍要求真实区域DOM和来源正文，不使用RSS替代；新增回归覆盖主入口失败、区域空首页、国际区域结果的完整选择链。
