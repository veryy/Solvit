# Solvit 0.43.8

0.43.7在完整设备检查未通过而未发布，原标签保留。

这一版继续打磨工作区文件页，让文件和目录成为页面主体，减少大按钮占用的空间。Git 工作台也使用同一套目录组件。

- 当前路径、上级目录、文件树与刷新集中在顶部导航。新建文件/目录归入「新建」，系统文件/聊天附件归入「导入」，导入备份归入「更多」；只展开菜单不会执行文件操作。
- 文件按紧凑行展示名称与大小，点击名称打开；移动/重命名和删除放进每行菜单。空目录保留清楚的提示，触摸按钮和完整无障碍名称继续保留。
- 进入目录失败时保留原路径及其对应文件，显示错误和重试入口；首次读取失败不再当成空目录。切换工作区会清理上一工作区的目录缓存，避免失败时显示旧文件名。
- 原有文本/代码预览编辑、外部修改检查、导入与备份、原生确认、文件树、Shell和Git操作继续使用既有业务链。页面由插件自己的HTML/JS绘制。
- 工作区插件更新为1.11.1，Git为1.3.2。原版内置包可保留设置、权限和停用状态升级，用户改过的包及卸载选择继续保留；没有新增插件权限。

0.43.8/build91，固定签名与数据格式继续沿用。覆盖更新保留数据，卸载仍会删除本地数据。完整远程门禁与下载核对完成前，本文件仅是候选说明，不表示已发布。
