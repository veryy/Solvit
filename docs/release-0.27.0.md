# Solvit 0.27.0：对话内授权、等待队列和聊天外观

明确选择角色时同时保存新对话默认。新建和重新打开对话使用绑定身份，聊天标题、输入提示和助手消息显示角色名称；已删角色保留阻断状态并允许重新选择，不自动扩大工具范围。

工具授权卡位于聊天输入区上方，可拒绝、允许一次或允许且不再询问。记住规则限定角色和当前版本工具。回复期间可以发送消息进入等待队列，逐项编辑、移除或立即发送并打断；打断等待前一轮取消和资源清理后才开始下一轮。停止或失败保留队列并暂停，可手动继续。当前队列只在ViewModel生命周期内保留，尚无进程死亡恢复。

设置 → 界面配置 → 聊天外观，支持12–24sp字体、气泡/紧凑/简洁样式及自动、自定义或即时显示。配置持久化并包含在加密配置备份中；显示速度独立于模型接收速度，不保证服务端逐字发送。默认工作区终端直接打开已有离线xterm.js与Android PTY，命令任务作为独立切换。
