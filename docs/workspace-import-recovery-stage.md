## 协议与边界

事务WAL放在工作区外的noBackupFilesDir，与0.38登记目录共存。原名移动前同步PREPARED记录，保存工作区相对目标/备份和原inode身份；发布前原子替换为PUBLISHING，保存暂存路径/身份；发布后COMMITTED。取消/异常先记录ROLLBACK，再清除暂存。正常结算删除事务，不删除保留的原文件备份。

重启先恢复事务，再清理登记暂存。目标已有新文件或并发名字时不覆盖；只有原备份身份仍匹配、目标缺失且提交状态不含歧义时，才能用原生不覆盖重命名恢复。PUBLISHING中暂存与新目标都消失，可能是Shell删过已发布文件，故保留备份、提示人工检查。COMMITTED不会因后来删除目标而复活旧文件。恢复结果先写notice再退休事务，避免恢复后又根据旧记录重复改名；关闭提示只删除宿主记录，不删工作区文件。进程内活动事务跨服务实例保护。

扫描限制每工作区20000条宿主目录项，报告最多显示最近100条；这不是全局容量配额。格式错误、越界、父目录符号链接、身份不匹配记录不授予改名权。同步日志面向进程死亡，不承诺所有文件系统上的断电/存储损坏恢复，也不提供对任意外部Shell的文件系统CAS。
