# 最近请求诊断

0.15.3 在设置底部新增“诊断 → 最近请求诊断”。此功能用于核对角色、工具范围和显示延迟，不改变模型协议或聊天内容。

Agent 在每一次实际调用 Provider 前记录当前请求的角色名称、协议/模型、消息数、系统上下文长度、提示段来源和实际工具名称。工具后续轮次也更新记录；角色白名单过滤后的工具集才进入诊断。记录只在内存中保留，不保存提示词正文、API 地址、密钥、Header、用户消息或工具参数。

耗时从点击发送开始，以单调时钟计算，区分首段文本/思考到达应用、首段文字显示、模型事件结束和显示结束。工具执行与审批可能包含在整轮时间中；“到达应用”是解析后的 ChatService 事件时间，不是网络首字节时间，不能据此单独断言服务端是否缓冲。

源码参考继续使用 DSH `packages/core/system-prompt` 的贡献来源与作用域设计，以及 Operit 的独立流式渲染调度。该服务按 Kotlin 插件注册；UI 读取只包含元数据的 StateFlow，JS 插件不能读取凭据或原始请求。

回归包括：敏感内容不进入诊断对象、每个 Provider 请求与诊断一致、工具过滤后记录、接收结束与显示结束时间不同，以及原生设置中实际查看诊断。[远程验证通过](https://github.com/veryy/Solvit/actions/runs/38160317381)，含测试、Lint、APK、固定签名和模拟器界面。发布入口见 [0.15.3](https://github.com/veryy/Solvit/releases/tag/v0.15.3)。0.15.2 不包含此功能；真实模型及真机仍待验收。
