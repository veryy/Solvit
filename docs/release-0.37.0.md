# Solvit 0.37.0：导入文件前审阅，再确认替换

候选阶段，尚未发布。当前公开版仍为0.36.2；下文描述本阶段代码，不代表新版APK已验收。

聊天附件或系统文件导入工作区时，同名文件不再只有报错。先显示现有目标文件的大小和完整SHA256，再由用户确认替换。提交时重新核对目标版本，Shell已经改动的文件会拒绝替换，保留已选附件以便重新审阅。

确认替换后，旧文件保留在同目录的`solvit-backup-UUID`，页面显示备份路径。文件管理、Git与终端都能看到这份原文件，检查后可以手动删除。取消、授权失效或提交失败会尝试恢复旧名字；如果Shell抢先创建了同名文件，则两份都保留，并提示恢复文件位置。该协议不锁住Shell或外部进程，旧名字移走至新文件发布之间存在短暂空窗，不承诺文件系统CAS。

没有同名文件时仍按原始字节新建，不改变PDF选页、OCR、图片缩略图与原始附件的关系。旧插件的create-only导入接口保留原语义。源文件和现有目标均限制20MiB，拒绝目录、符号链接和内部路径。保留备份不会自动清理；导入进度/取消、异常暂存回收与配额继续在后续路线中处理。

工作区插件1.8.0/API25，Git插件1.2.4/API20。已发布的1.7.0/1.2.3原包及所有更早历史下载保留，不向旧宿主发送API25工作区包。升级保留项目规则设置与授权，用户修改的插件和卸载选择不被覆盖。
