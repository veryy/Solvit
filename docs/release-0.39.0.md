# Solvit 0.39.0 候选

**候选完整构建与设备已通过，正式标签门禁及公开下载仍待完成。** 已发布版本仍为[0.38.0](https://github.com/veryy/Solvit/releases/tag/v0.38.0)。

这次补文件导入在应用被系统结束后的恢复。替换前记录原文件与备份身份；重新启动后，能恢复的原文件放回原路径，已发布的文件保留，并发Shell写入不覆盖。工作区插件显示“上次导入恢复”，点开查看具体路径和结果；关闭提示会保留文件和备份。

API27工作区1.10.0使用JS页面展示恢复结果，Git共享页面更新到1.2.6/API20；旧工作区1.9.0和Git1.2.5仍保留原始下载。仅迁移原样内置包，保留插件设置、权限、禁用状态、用户修改与卸载选择。

远程门禁增加五种真实Android进程强杀场景：准备、发布前、提交后、并发同名和提交后删除新文件。外部adb结束进程，重新启动后核对实际文件、备份、Shell、插件HTML和关闭提示；这些结果在执行通过前不算完成。

Python、Node.js/npm、Java与免Root Linux工作区继续保留，见[安装与使用指南](linux-environment.md)。PRoot不会授予Android额外权限，也不是完整虚拟机。持久化日志不承诺断电恢复或任意Shell写入下的文件系统CAS。容量与备份管理、Git克隆恢复、真实模型任务、ARM64真机、真实GitHub账号插件写入和stdio MCP继续保留，屏幕操控暂缓。

0.7.0起使用固定签名；覆盖更新保留数据，卸载会删除配置、聊天和Linux环境。0.6.0及之前证书不同，不能直接覆盖。

候选[38675621760](https://github.com/veryy/Solvit/actions/runs/38675621760)完整报告核对：537单元、79常规设备均零失败/错误/跳过，另外五种外部force-stop/重启恢复均通过；Lint、固定签名和覆盖升级通过。两项界面测试先分别复现历史滚动位置、键盘抬升导致旧触摸坐标问题，修正后同一生产APK的8轮×2项诊断和完整设备回归通过，详见阶段记录。市场API27公开HTTPS已比对27目录、48历史包和2新包完整字节数/SHA256。正式Linux与公开APK仍以标签最终结果为准。
