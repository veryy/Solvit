# Solvit icon

An original pixel S assistant: terracotta `#C46648` on warm cream `#F6F1E7`.
The two square cutouts form a small face while the silhouette keeps the S readable.

- `solvit-icon.svg`: editable vector master, 108 × 108 viewport.
- `solvit-icon.png`: 1024 × 1024 PNG preview.
- `solvit-icon-masks.png`: rounded, circular and square mask previews.
- Android vector foreground and adaptive/monochrome resources live in `app/src/main/res`.

Drawn directly as SVG/Android vectors and rendered with Pillow; no image generation API was used.
The artwork was inspected at small size and under common launcher masks. Device launcher and themed-icon appearance still need real-device validation.
