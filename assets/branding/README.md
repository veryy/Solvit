# Solvit icon

Current icon: original **orbital S**, drawn entirely with strokes. Pale mint `#D8EEE7` on ink `#14252D`.

- `solvit-icon-line.svg`: editable vector master.
- `solvit-icon-line.png`: 1024 × 1024 preview.
- `solvit-icon-line-masks.png`: common launcher mask previews.
- Android adaptive and monochrome resources use the line design.

The older pixel design remains as an archived draft in `solvit-icon.*`.
Drawn as SVG/Android vectors and rendered with Pillow; no image generation API was used.
Device launcher and themed-icon appearance still need real-device validation.
