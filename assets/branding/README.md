# Solvit icon

Current icon: original **radiant core**, built from a hollow focus and six groups of three line rays. No letters or solid symbol fills. Off-white `#F1F1ED` on charcoal `#111113`.

- `solvit-icon-radiant.svg`: editable vector master.
- `solvit-icon-radiant.png`: 1024 × 1024 preview.
- `solvit-icon-radiant-masks.png`: common launcher mask previews.
- Android adaptive and monochrome resources use the radiant design.

Earlier pixel and orbital S assets remain as archived drafts.
Drawn as SVG/Android vectors and rendered with Pillow; no image generation API was used.
Device launcher and themed-icon appearance still need real-device validation.
